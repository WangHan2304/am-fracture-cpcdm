# A leakage-free validation protocol and mechanism-keyed applicability domain for orientation-resolved ductile damage descriptors in additively manufactured metals (Taylor CP-CDM)

Reproducibility archive for the manuscript submitted to *Engineering Fracture Mechanics* (Elsevier), transferred there at the editors' suggestion from the *International Journal of Mechanical Sciences*. It contains the solver code, the curated literature dataset, the result JSONs behind every reported number, and the LaTeX sources.

> **Version of record and priority.** This archive is the citable version of record for the work described here, released under the MIT License (see the LICENSE file) and archived with a versioned DOI: [10.5281/zenodo.23257091](https://doi.org/10.5281/zenodo.23257091). The companion manuscript is submitted to *Engineering Fracture Mechanics*. Please cite the manuscript and/or the DOI if you build on this work. The DOI pins this archive as released at that version; later commits, including the current manuscript sources, are not covered by it.

## Contents
- `simulation/src/` - Taylor-type crystal-plasticity continuum-damage model (TaylorCPCDM), CP-CDM, materials, RVE generator.
- `simulation/` - experiment / calibration / blind-test / sensitivity / Bayesian drivers (e.g. `sensitivity_sobol_beta4.py`, `model_simplification.py`, `statistical_upgrade_bayes.py`, `directional_bayes.py`, `blind_predict_frozen.py`, `fullfield_skfem.py`).
- `simulation/data/` - curated literature dataset (`extended_literature_dataset.csv`, process/source group JSONs, extraction log).
- `simulation/output/` - result JSONs backing each headline number; `version_manifest.json` records SHA-256 hashes (generated by `gen_reproducibility.py`).
- `simulation/figures/` - manuscript figures.
- `submission_EFM/` - **current authoritative manuscript sources**: `manuscript_efm.tex` (Elsevier `elsarticle.cls`, vendored here) and `supplementary/supplementary_efm.tex`, with the compiled PDFs and `highlights_efm.txt`.
- `manuscript/` - earlier frozen variants of the same work, prepared for the *International Journal of Damage Mechanics*: `manuscript_sagej.tex` (`sagej.cls`), `manuscript_main.tex`, `supplementary.tex`. Kept for provenance and no longer updated; their title wording predates the current submission.

## Reproducing
Python 3.13, NumPy, SciPy (seed 42). Run a driver, e.g.:
`python simulation/sensitivity_sobol_beta4.py`
- See `simulation/REPRODUCIBILITY.md` and `simulation/REPRODUCIBLE_FULLFIELD_REFERENCE.md` for the fixed seed/mesh/increment per result.
- `version_manifest.json` pins the result artifacts; the manuscript sources are validated by building them, not by hashing.
- Manuscript build: run `pdflatex` twice on `manuscript_efm.tex` from inside `submission_EFM/` (class and package shims are vendored there; figures resolve through `../simulation/figures/`).

## Note on data
Third-party NIST mds2-3402 raw data (downloaded via the NIST AM-Bench tooling) is **not** redistributed here (see Data Availability in the manuscript); only the source's published group means are used.
