## 0. 起点：现有框架的实测约束

被改造的求解器是 `simulation/fullfield_3d_cpfem.py`（**未改动**），其结构为：

* 网格 `ng×ng×ng` 个 hexa8 单元（每单元 = 1 个晶粒，`ng=3` → 27 晶粒），每单元 `2×2×2` 高斯积分
  → 积分点数 `n_ip = 8·ng³`（`ng=3`：216；`ng=4`：512）。
* 位移控制单轴拉伸，`x=0` 面固定、`x=L` 面控制位移，其余自由（单轴应力态）。
* 本构：晶体塑性 + Lemaitre 型耦合损伤（`dD = (Y/S_eff)^s · dp · f_AM`，`dp` 为等效塑性应变增量），
  每个残差评估内部从上一个收敛状态起**重跑 `n_sub=30` 个子步**（状态在 Newton 迭代中不更新）。
* Newton：阻尼 Newton + **有限差分数值切线**（对每个自由自由度做中心差分），切线为稠密矩阵
  并用 `np.linalg.pinv` 求逆；框架内**没有稀疏线性求解器**，也没有组装好的质量/拉普拉斯矩阵。
* 断裂判据与 ef 定义：`D_agg >= Dc`（`D_agg` 为积分点 D 的算术平均）或局部化失稳
  （损伤激活后平衡失稳 + 步长缩减到下限），ef 取触发步（`Dc` 越界时线性插值）。

实测成本（本机 Intel i7-14700KF，20 核 / 28 逻辑核；**单进程、空载**；
`simulation/_bench_ff3d.py`、`_bench_ng4.py`、`_bench_nl_overhead.py`、`_bench_matvec.py`）：

### 框架基线（局部损伤，`ng=3`，`eps_step=1e-3`）

| 量 | 实测 |
| --- | --- |
| 积分点数 `n_ip = 8·ng³` | 216 |
| 自由自由度数 `n_free` | 157 |
| 单次 `_residual`（含 30 子步本构积分） | **19.3 ms** |
| 单次 `_tangent`（`2·n_free+1 = 315` 次残差评估） | **14.7 s** |
| 单增量总成本（切线 + Newton + 线搜索） | **≈16 s / 增量** |
| 既有 Ti64 0° 单方向实际墙钟（R13 日志 `ff3d_ti64_0_log.txt`） | 5567 s ≈ 93 min（347 个增量，含自适应步长缩减至 5e-5） |

### `ng=4`（64 晶粒）基线

| 量 | `ng=3` | `ng=4` | 比值 |
| --- | --- | --- | --- |
| `n_ip` | 216 | 512 | 2.37 |
| `n_free` | 157 | 322 | 2.05 |
| `_residual` | 19.3 ms | **102.7 ms** | 5.3 |
| `_tangent` | 14.7 s | **66.2 s** | 4.5 |
| 预算（同上，≈350 个增量） | ≈1.6 h | **≈7 h** | — |

**一个必须先修掉的结构性障碍**：原 `fullfield_3d_cpfem.py` 把晶粒数写成模块常量
`NGRAIN = NG**3 = 27`，在 `__init__` 里用它构造 `TaylorCPCDM`，同时把
"单元编号 = 晶粒编号"（`gid = e`）直接当索引用。因此 **`ng=4` 在原文件里根本跑不起来**
（实测 `IndexError: index 27 is out of bounds for axis 0 with size 27`，见 `_bench_ff3d.py` 输出）。
新文件在构造时把该模块全局**临时**改写为 `ng³`（只在内存里，绝不改动磁盘上的原文件），
从而让 `ng=4` 可用，同时保证 `ng=3` 路径不受影响。

关键含义：**单方向预算被数值切线支配**（≈90% 的时间），而切线成本 = `2·n_free ×` 单次残差成本。
任何在 `_integrate_batch` 内部增加每子步开销的方案，会被放大 `2·n_free×n_inc` 倍；
任何增加未知数个数的方案，会同时抬高 `n_free` 和残差维度。这是选型的核心约束。

## 1. 第一步：三条路线评估

### 路线 1 — 积分型非局部损伤（选定）

**做法**：把损伤的驱动量（等效塑性应变）做非局部平均，损伤演化率改用非局部量驱动。
积分点坐标列表 + 预计算稀疏权重矩阵 `W`（截断半径 `R_cut ≈ 3 l_c`，几何常量，只算一次）；
每个子步做一次矩阵-向量乘。

| 维度 | 评估 |
| --- | --- |
| 实现改动量 | **最小**。新增 `ip_coords()`、`build_weights()`（~40 行）+ 一份 `_integrate_batch` 拷贝（其中 **2 行**是本构改动）+ 状态字典加一个 `pbar` 键。不改动 FE 组装、不改动 Newton、不改动判据。 |
| 对 damped Newton 收敛性的影响 | **有利**。`W` 是低通（平滑）算子，把损伤从"单点失稳"变成"邻域协同软化"，局部 D 梯度被削平，软化不再由单点主导。不增加 Newton 未知数，残差维数不变。 |
| 对数值切线的影响 | **自动、且代价可忽略**。切线是有限差分，非局部耦合通过 `_residual → _integrate_batch` 自然进入：扰动某个节点位移 → 改变其邻域若干积分点的 `dp` → `W@dp` 又改变所有积分点的驱动量。**同一进程内交替实测**（`_bench_nl_overhead.py`，排除并发负载干扰）：<br>`ng=3`：残差 19.27 → 19.96 ms（**×1.035**），切线 14.68 → 15.29 s（**×1.042**）<br>`ng=4`：残差 102.72 → 107.94 ms（**×1.051**），切线 66.24 → 69.63 s（**×1.051**）<br>切线开销比与残差开销比一致（1.051 vs 1.051），**证明非局部耦合确实完整进入了数值切线**，且代价完全由每子步那一次 matvec 决定。 |
| 权重矩阵尺寸 | `ng=3`：216×216，非零 42792（每行 ≈198）；`ng=4`：512×512，非零 164312（每行 ≈321，`l_c=0.25` 时）。matvec 实测：csr 15.5 µs / 85.4 µs，稠密 3.8 µs / 27.6 µs —— 两种实现都在微秒量级，相对 20 ms / 100 ms 的残差评估可忽略。（注：微秒级的 matvec 选择稠密还是稀疏对总成本无实质影响，本实现保留 csr 以便 `ng` 更大时退化。） |
| 稳定性风险 | 低。无新增非线性、无新增未知数、无非凸自由能项。 |
| 单方向运行时间预算 | 既有 50–93 min × ~1.04 ≈ **基本不变**。 |

**为什么这是最小成本路线**：它把"正则化"表达成一个**与状态无关的常数线性算子**。
常数算子意味着 (a) 只算一次；(b) 梯度精确（不引入求解器误差）；(c) 不改变问题规模。
框架里其余一切（数值切线、damped Newton、自适应步长、判据）都无需改动。

### 路线 2 — 隐式梯度（Helmholtz 滤波）

**做法**：解 `a − l_c²∇²a = a_local`，用 `a` 驱动损伤。

| 维度 | 评估 |
| --- | --- |
| 实现改动量 | **中等偏大**。需要一个在**积分点离散**上一致的（质量 + 拉普拉斯）矩阵，边界条件需要新规定；框架里只有节点位移自由度，没有标量场自由度，也没有稀疏求解器——需要新引入 `scipy.sparse.linalg` 与一套标量场装配。 |
| 对 Newton 的影响 | 驱动量 `a` 变成需在每次残差评估中解出的**隐式量**（`a_local` 是历史相关量），即每个子步一次稀疏线性解，即每个残差评估 30 次解。 |
| 对数值切线的影响 | **有害**（推算，非实测）。有限差分切线需要对每个扰动自由度重算 `a`，即每次残差评估内的 30 次线性解都要重做；`2·n_free = 314` 次/切线 → 每增量约 314×30 ≈ 9400 次稀疏解。即使单次 1 ms，也约 9.4 s/增量，相对实测 14.7 s/增量的切线预算再抬高 ~64%。 |
| 稳定性风险 | 中。Helmholtz 滤波的核是上凸的、单调的，稳定性本身可控；风险主要在实现（离散一致性、边界、稀疏求解收敛）。 |
| 结论 | **不选**。收益与路线 1 相同（都给出有限内部长度），但实现量和切线代价都明显更高；在没有标量场自由度与稀疏求解器的情况下性价比差。 |

### 路线 3 — Allen-Cahn / Ginzburg-Landau 相场最小实现

**做法**：引入相场变量 `φ`，加梯度能项与演化方程，与损伤/塑性耦合。

| 维度 | 评估 |
| --- | --- |
| 实现改动量 | **最高**。需要在 Newton 系统里扩展未知数（`3·n_node → 3·n_node + n_node` 或 `+ n_ip`）、扩展残差与切线、新增界面能参数（`G_c`、`l_c`、迁移率）并与现有 `S_eff / Dc` 标定对齐；还需要重新定义 ef 判据（相场模型的"断裂"是 `φ` 贯通，与现有 `D_agg ≥ Dc` 不是同一个量），从而**破坏与既有 R13 四方向结果的判据一致性**。 |
| 对 Newton 的影响 | **最大**。相场是强非凸（双井势）耦合问题，`φ` 与 `D` 之间是双向反馈；现有 damped Newton + 有限差分切线在这种强耦合下收敛域很窄，步长会被迫缩到自适应下限，运行时间不可控。 |
| 对数值切线的影响 | 切线规模从 `n_free × n_free` 上升到 `(n_free + n_φ)²`，且 FD 评估次数变为 `2·(n_free + n_φ)`；`ng=3` 时若 `φ` 在节点上则 `n_free + n_φ = 157 + 64 = 221`，切线成本 +41%；若在积分点上则 +138%。 |
| 稳定性风险 | **最高**。 |
| 结论 | **不作为本轮交付**。它需要重做判据与标定，属于"更高保真 follow-on"，不是"最小可行正则化"。见 §4 诚实声明。 |

### 选型结论

> 在"hexa8 + damped Newton + 数值切线 + 每残差 30 子步重积分"的现实现上，
> **积分型非局部损伤**是唯一同时满足（i）本构改动只有常数线性算子、（ii）不增加 Newton 未知数、
> （iii）切线自动包含非局部耦合、（iv）单方向运行时间基本不变 的路线。
> 隐式梯度需要框架不具备的稀疏求解与标量场装配；相场需要重做判据与标定。
> **执行路线 1；相场作为更高保真 follow-on 明确标注（未实施）。**

## 2. 第二步：实现要点

新文件 `simulation/fullfield_3d_cpfem_nonlocal.py`（**原 `fullfield_3d_cpfem.py` 一字未改**）。
用子类 `FullField3DNonlocal(_Base3D)`，保证 `lc = None` 时**直接调用父类方法**。

### 2.1 非局部化方案

对每个高斯积分点的**等效塑性应变**做非局部平均（Pijaudier-Cabot & Bažant 型积分非局部损伤）：

```
p̄_i   = Σ_j W_ij · p_j                 (非局部累积等效塑性应变)
dp̄_i  = Σ_j W_ij · dp_j                (非局部等效塑性应变增量)

损伤门与驱动量同时替换：
  local    : act = (p > p_D)  & (dp  > 0) ;  dD = (Y/S_eff)^s · dp  · f_AM
  nonlocal : act = (p̄ > p_D) & (dp̄ > 0) ;  dD = (Y/S_eff)^s · dp̄ · f_AM
```

其余（滑移/硬化、`Y` 能量项、`f_AM`、`p_D` 门、D 上限 0.99、`dD` 截断 0.02、
`D_agg ≥ Dc` 判据、ef 定义、`n_sub=30`、收敛容差、自适应步长缩减）**与原文件逐语句相同**。
仅 `dp` / `p` 换成非局部量 `dp̄` / `p̄`，这就是全部的本构改动（`_integrate_batch_nl` 中 2 行）。

### 2.2 权重矩阵

```
W_ij = exp( −(r_ij/l_c)² ) / Σ_k exp( −(r_ik/l_c)² ) ,   仅保留 r_ij ≤ R_cut = 3·l_c
```

* **行归一化**：保证 `W @ (c·1) = c·1`，即**常数场被精确保持**（实测偏差 4.4e-16）。
  这对边界积分点很关键——截断使边界点邻居更少，若用固定权重会造成边界处的人为衰减。
* **含自项** `W_ii`（`r=0` → 权重 1），即"非局部 = 自身 + 邻域"的加权平均。
* **非对称**：实测 `max|W − Wᵀ| = 0.0242`。行归一化会破坏对称性（边界行与内部行的归一化系数不同）。
  这是"质量守恒"（行和 = 1）与"对称性"之间常规的取舍，本文取前者；
  注：非对称性**不影响**解的正确性——`W` 只作为固定算子出现在本构里，不参与任何对称求解。
* **一算一次**：`W` 只依赖积分点几何，与位移/状态无关，因此在 `__init__` 中构造一次并缓存为
  `scipy.sparse.csr_matrix`。
* **周期性**：采用 RVE 内的欧氏距离，**未**做周期性镜像。与 FE 边界条件（非周期、位移控制面）
  保持一致；这是一个可在后续工作中改进的点（见 §4）。

### 2.3 内部长度 `l_c` 的取值

RVE 为归一化单位立方体，`ng=3` 的晶粒尺寸 `h = 1/3`，`ng=4` 的晶粒尺寸 `h = 1/4`。

| 设置 | 定义 | `ng=3` | `ng=4` | 物理含义 |
| --- | --- | --- | --- | --- |
| `lc_phys` | 固定为 27 晶粒 RVE 的 **1 个晶粒**尺寸 | 0.3333 | 0.3333 | 真正的材料内部长度（与网格无关） |
| `lc_scaled` | **1× 当前网格**晶粒尺寸 | 0.3333 | 0.2500 | 网格相关长度（"`l_c ∝ h`"约定） |
| `lc_sub` | 亚晶粒尺度（敏感性） | 0.2500 | — | `l_c < h` 时的退化情形 |

"`l_c` 固定为物理长度"与"`l_c` 随网格缩放"两种设置都测，正是为了回答
"非局部化能否消除损伤局部化的网格依赖"——只有 `lc_phys` 才算真正的正则化检验。

### 2.4 状态与记录

* 状态字典新增 `pbar`（非局部累积等效塑性应变），与 `p` 同步推进（`W` 线性 → 二者等价）。
* `run()` 结构与原文件逐语句一致，仅**增加**记录：逐步日志（`eps / sig11 / Dagg / iters / eps0 / wall`）、
  D 场检查点快照（`eps = 0.04 / 0.06 / 0.08 / 0.10 / 0.12`）与终止步 D 场。
* 记录**未**触碰任何物理量，因此不改变任何解。

### 2.5 与既有协议的一致性

| 项 | 既有 R13 协议 | 本文件 |
| --- | --- | --- |
| 材料/取向 | Ti64 0° | 同 |
| `S0` / `Dc` | 0.32 / 0.42 | 同 |
| `n_sub` | 30 | 同 |
| 应变速率 | 1e-3 | 同 |
| `seed` | 42 | 同 |
| 判据 | `D_agg ≥ Dc` 或局部化失稳 | 同 |

   是最严格的一组对照——它同时改变晶粒数和相对分辨率，偏移仍只有 −1.75%。

  参与损伤的积分点比例从 75.9% 骤降到 26.6%。
- **反例**：`mean\|\nabla D\|/h` 在非局部算例上仍有 −28.4% 的网格变化。

  结论应以两个核化指标为准；此处不作为"非局部场仍不客观"的证据，但也不掩盖。

#### 3.5.3 是否消除了网格依赖——直接回答

- **按 `ef`：没有完全消除。** 残余 1.75%~3.97%（局部为 15.92%）。
- **按 D 场的两个核化客观性指标：基本消除。** 残余 ≤3%（局部为 +20% / +44%）。
- 因此本工作给出的诚实表述是：
  **积分型非局部损伤把损伤局部化的网格依赖压低了一个数量级，并把失效分支拉回同一机制，
  但没有做到严格网格无关**；残余项的来源是 RVE 随机实现改变与缺少周期性，与正则化本身无关。

### 3.6 `l_c` 敏感性扫描（ng=3，27 晶粒）——本工作新增

#### 3.7.3 四条结论

1. **方向序保持不变**：0° > 45° > 90° 在全部五种设置下都成立，非局部化没有破坏方向性。

2. **非局部化把"软"方向抬高得更多，于是压缩了方向间的差异**。相对同网格局部结果，
   `l_c=0.125` 时抬高 +2.02%（0°）/ +4.88%（45°）/ +3.29%（90°）；
   `l_c=1` 晶粒时 +9.32% / +24.22% / +24.15%。方向越软（`ef_Taylor` 越小）被抬高越多，
   三方向相对 Taylor 的偏差带因此**收窄**：

   | 设置 | 偏差带 | 带宽（百分点） |
   | --- | --- | --- |
   | 局部 | [−14.19%, +24.98%] | 39.2 |
   | `l_c=0.125` | [−11.37%, +27.50%] | 38.9 |
   | `l_c=1` 晶粒 | **[+6.53%, +36.63%]** | 30.1 |

3. **偏差带的"形状"比"宽度"变化更重要**。局部模型下 45°/90° 为**负**偏差、0° 为**正**偏差，
   Taylor 参考解**从两侧包住**全场结果——这正是既有"约束依赖偏差带"论证的支点。
   强非局部化（`l_c=1` 晶粒）把这个结构破坏掉：三个方向**全部高估** Taylor，
   下界由 −14.19% 变为 **+6.53%**。弱非局部化（`l_c=0.125`）则基本保持原结构。
   **这是对既有"偏差带"论证的限定条件，不是一个支持性结果。**

4. **终止机制需要逐例标注**：`l_c=1` 晶粒的 45° 以 `aggregate_Dc` 终止；
   45° 的 `l_c=0.125` 与 90° 的两个非局部算例以 `localization_onset` 终止
   （某增量在步长下限 `3.125e-05` 仍不收敛，被既有协议判定为局部化起始）。
   两类都符合既有判据（"`D_agg ≥ Dc` 或局部化 onset"），但不是同一种机制。
   **在 90° 上，非局部化没有消除局部化失稳，只把它的应变推后**（0.0665 → 0.0687 / 0.0826）。

## 4. 稳定性观察、失败记录与诚实声明

### 4.1 收敛性与稳定性（实测）

**没有任何算例发散、出现 NaN，或触发 `max_strain` 截断。**
6 个 ng=3 的 **0° 主算例全部以 `D_agg ≥ Dc` 收尾**（无一个是 `localization_onset` 或
`numerical_limit`）；三方向扩展（§3.7）与 64 晶粒则出现了 `localization_onset` 终止，
逐例标注见下表与 §3.5、§3.7。

0°、ng=3 的稳定性指标随非局部化程度（`n_eff`）单调改善：

| 算例 | `n_eff` | 步长缩减次数 | 末步 `eps0` | Newton 迭代总数 | 墙钟 `wall_sec` |
| --- | --- | --- | --- | --- | --- |
| 局部 `e1e3` | 1 | 5 | 3.125e-05（下限） | 3527 | 7613 s |
| 局部 `e2e3`（R13 复现） | 1 | 6 | 3.125e-05（下限） | 3547 | 7564 s |
| `l_c=0.0625` | 1.03 | 5 | 3.125e-05（下限） | 3521 | 7617 s |
| `l_c=0.125` | 3.76 | 3 | 1.25e-04 | 3031 | 6097 s |
| `l_c=0.25` | 28.88 | **1** | 5e-04 | 2881 | 5822 s |
| `l_c=1/3` | 55.45 | **1** | 5e-04 | 2810 | 6053 s |

（墙钟取 `wall_sec`，即主求解本身；含 Taylor 参考解调用的 `wall_sec_total` 见各算例 JSON，约多 35 s。
§3.3/§3.6 表中引用的是 `wall_sec_total`。）

三点观察：

1. **步长缩减次数随 `n_eff` 单调下降**（5 → 3 → 1）。非局部化直接打断了
   "单积分点软化失控 → 增量不收敛 → 步长减半"的循环。
2. **Newton 迭代总数下降约 20%**（3527 → 2810）：同一载荷历程需要的迭代更少。
3. **非局部算例反而更快**：尽管单增量成本 +4.2%，`l_c ≥ 0.25` 的两个算例墙钟
   （5822 / 6053 s）比局部（7613 s）**短约 20–24%** —— 因为它们省掉了步长缩到 3.125e-05 的长尾
   （局部算例最后约 140 个增量每个只推进 3e-5 ~ 1e-4）。
   这修正了"正则化必然更贵"的直觉：在这套实现里正则化让整个求解**更快**。

**数值切线代价（同进程交替采样 + 重复取最小值）**：非局部/局部的**切线**耗时比与
**残差**耗时比**一致**——两次加固后的运行给出：ng=3 切线 **1.0292~1.0419**、残差 **1.0341~1.0392**；
ng=4 切线 **1.0569~1.0603**、残差 **1.0378~1.0485**。**每一轮里两个比值的缺口都在 2.3 个百分点以内**
（实测 0.8 / 0.8 / 1.0 / 2.3 pp）。这**支持但不能单独证明**"非局部耦合进入了切线"：
若切线里**缺**了非局部项，切线比值应停在 **1.000** 而残差比值约 1.04，即出现约 **4 pp** 的缺口；
实测缺口只有 0.8~2.3 pp，与"已包含"一致，但在噪声量级（±2 pp）下**判别力有限**。
**决定性证据在代码结构上**：数值切线是对**同一个** `_residual` 做有限差分，而该残差走的正是
含非局部分支的 `_integrate_batch_nl`，因此 `dp̄` 的变化必然通过切线传播（见 §2.1、§3.1 的逐位自检）。

> **口径声明**：本机同时跑着其它进程，绝对耗时会在 1~2 个百分点内浮动。因此本报告只对
> "**比值量级约 1.03~1.06**"与"**切线比值 ≈ 残差比值**"这两条结论负责，**不把任一次运行的
> 小数位当作固定值**。最近一次运行的逐条原始样本保存在结果 JSON 的 `cost_bench`（含
> `residual_samples_ms` / `tangent_samples_s` / `spread_pct`），读者可自行核验。

> **一次被抓住的污染读数（如实记录）**：本基准的第一版每个切线只测一次、且先把 local 全测完
> 再测 nonlocal，结果给出 ng=3 的**残差**开销比 **2.4789**——这在物理上不可能：非局部残差只多
> 两次稀疏矩阵-向量乘（ng=3 时 2×37.65 µs），相对 19.66 ms 的残差是 0.4%。
> 原始样本显示第 4、5 轮采样被同机其它进程顶到 37.86/49.58 ms（local）与 51.29/50.77 ms
> （nonlocal），即一次 **2.5× 的抢占**。基准已重写为"交替采样 + 重复取最小值"，
> 每一条原始样本都保留在 JSON 的 `cost_bench` 里，读者可自行核验。

> **一处已识别但未实施的优化**：在本问题规模下稀疏核比稠密核更慢
> （216×216：CSR 37.65 µs vs 稠密 6.43 µs；512×512：128.01 µs vs 29.65 µs，两者一致到 1.3e-15），
> 且实测每残差开销（0.67 ms，3.4%）约为两次核调用的 9 倍，说明非局部成本主要来自
> Python/scipy 调用开销而非核本身。改用稠密核 + 提前构造算子可以抹掉大部分——**本轮未做**，
> 因为此时改动会使已完成的 15 个算例失效。

### 4.3 诚实声明

1. **相场未做，理由明确**。Allen-Cahn / Ginzburg-Landau 相场需要扩展 Newton 未知数、
   加入梯度能项、标定界面参数，并且**必须重新定义断裂判据**（相场的"断裂"是 `φ` 贯通，
   与 `D_agg ≥ Dc` 不是同一个量），这会**破坏与既有 R13 四方向结果的判据一致性**。
   它被明确标注为 **"更高保真 follow-on"**，**本轮未实施**；也没有用别的近似充当"相场"。
2. **参数未重新标定（最重要的一条）**。`S0 = 0.32`、`Dc = 0.42`、`p_D = 0.05` 都是
   **局部模型**的标定值。非局部化把驱动量 `A` 换成 `Ā` 之后，`Ā` 的**量级**会变：
   实测 0°、ng=3 在 `ε ∈ [0.05, 0.10]` 区间，`dD_agg/dε` 由局部 4.0199 降到
   `l_c=0.125` 的 3.9199（×0.975）、`l_c=0.25` 的 3.3857（×0.842）、
   `l_c=1` 晶粒的 3.0922（**×0.769**）；
   同一应变处的损伤水平也被压低（`ε=0.08`：0.1091 → 0.0635）。
   也就是说**驱动量本身被动过**，而文献惯例是非局部化后**重新标定材料参数**。
   因此本工作报告的 ef 偏移，严格地说应理解为
   **"在既有标定下把驱动量换成非局部量的效应"**，**不是**"经标定后的非局部模型预测"。
   §3.6 的 `l_c → 0` 极限（+0.031%）之所以回到局部值，正是因为那条路径下 `W ≈ I`、
   `Ā ≈ A`，量级没有变。
3. **`l_c = 1–2 晶粒`在本 RVE 上偏大**。`l_c/h = 1` 时 `n_eff ≈ 55` 个积分点 ≈ **6.9 个晶粒**，
   自身权重只剩 **4.7%** —— 这已接近 RVE 尺度的平均（RVE 只有 27 个晶粒），
   超出了"局部损伤的微扰"范畴。有意义的区间在 `l_c ≲ 0.5` 晶粒（`n_eff ≲ 4`）。
4. **非周期核，且边界截断是一阶效应**。权重只用 RVE 内的欧氏距离，**未做周期性镜像**；
   `l_c ≥ 0.25` 时 **100%** 的积分点邻域都触及 RVE 表面（`nonlocal_kernel_stats.json`）。
   **这是本实现最大的已知近似**，也是"值得做但本轮没做"的一步。
5. **网格依赖结论只按实测数据说话**（§3.5），不外推。
6. **ef 可比性**：每个算例的 `fracture_type` 都在 JSON 中记录。以 `aggregate_Dc` 终止的
   ef 是 `Dc` 越界插值；以 `localization_onset` 终止的 ef 是"最后一个收敛步"。
   同类之间严格可比，跨类比较需注意（§3.7 第 4 条、§3.5 已逐例标注）。
   没有任何算例是 `max_strain` 截断产生的下界。
7. **负结果如实报告**：非局部化**没有**把 0° 相对 Taylor 的正偏差拉回既有方向带，
   反而把它从 `+24.98%` 推高到 `+33.55%`（`l_c=0.25`）/ `+36.63%`（`l_c=1` 晶粒）。
   如果目标是"用正则化改善 0° 与 Taylor 的一致性"，**本结果为否**。
   换用步长收敛的 Taylor 参考（§3.8.2）该结论不变：`+92.51%` → `+96.40%` / `+110.46%`。
8. **一处必须说明的口径差异**：R13 归档的 `ef_ff = 0.1389` 是"最后一个收敛步"
   （其日志终止于 `Dagg = 0.4157`）；本工作同一算例继续跑到真正的 `Dc = 0.42` 越界，
   得 `0.13967`（+0.55%）。两者的损伤历史**逐位相同**（§3.2），
   差异纯粹来自 ef 定义的截断方式，不是代码差异。
9. **偏差带依赖 Taylor 参考的步长档位（本工作新发现，需手稿层面拍板）**：R13 锁定的 `ef_Taylor`
